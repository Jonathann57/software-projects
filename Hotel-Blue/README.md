# HOTEL BLUE

Este proyecto está desarrollado en C# con ASP.NET Core. 
Está diseñado para la gestión de un hotel. Permite gestionar la recepción de habitaciones, salidas del hotel, pedir servicio a la habitación (gestión de tienda/productos), administrar el mantenimiento y estado de las habitaciones, gestionar empleados, y generar reportes de recepción y consumo de clientes.

## Requisitos Técnicos

- **Visual Studio Code** (Editor de código principal).
- **SDK de .NET 8.0** (Necesario para compilar y ejecutar el proyecto).
- **C# Dev Kit** (Extensión recomendada en VS Code).
- **DB Browser for SQLite** o la extensión **SQLite Viewer** (Para visualizar la base de datos local).
